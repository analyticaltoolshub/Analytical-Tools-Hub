About Analytic Hierarchy Process

Analytic Hierarchy Process is a structured method for multi-criteria decision-making. It asks experts to compare criteria and alternatives in pairs, converts those judgements into priority weights, and combines the weights into an overall ranking.

Guidance

  1. Define the decision goal, criteria, and alternatives in the questionnaire design section.
  2. Choose whether each criterion is subjective judgement or objective measured data. Objective criteria need a direction such as higher-is-better or lower-is-better.
  3. Export the blank questionnaire JSON and send it to the expert or decision-maker.
  4. The expert imports the questionnaire, answers each pairwise question, and exports the completed response JSON.
  5. Load one or more completed response files into the analysis section, enter measured values for any objective criteria, and calculate the ranking.
  6. Review consistency ratios before using the ranking to support a decision.
  7. Optionally turn on Scenario Planning after calculation to test whether changes in criterion importance alter the preferred alternative.

Methodology, Assumptions, and Limitations

Formula Logic

Notation
E = number of experts, n = number of compared elements, aij(e) = expert e's judgement comparing element i with element j, wi = priority weight

Reciprocal pairwise matrix
aji = 1 / aij,   aii = 1

Multiple-expert aggregation
Aij = (∏e=1E aij(e))1/E

Row geometric mean
GMi = (∏j=1n Aij)1/n

Normalised priority weight
wi = GMi / ∑k=1n GMk

Final alternative priority
Sa = ∑i=1n wi × pai, where pai is alternative a's local priority under criterion i

Objective criterion, higher is better
pai = xai / ∑a xai

Objective criterion, lower is better
pai = (1 / xai) / ∑a (1 / xai)

Sensitivity scenario
w′k = s,   w′j = wj × (1 - s) / (1 - wk)

Consistency Ratio

Consistency vector
(Aw)i / wi

Principal value
λmax = (1 / n) ∑i=1n ((Aw)i / wi)

Consistency index
CI = (λmax - n) / (n - 1)

Consistency ratio
CR = CI / RI

RI is Saaty's random index for a matrix of size n. A CR around 0.10 or lower is commonly used as review guidance, not proof that the judgement is objectively correct.

Saaty Scale

Ratings use 1 equal, 2 equal to moderate, 3 moderate, 4 moderate to strong, 5 strong, 6 strong to very strong, 7 very strong, 8 very strong to extreme, and 9 extreme preference.

Assumptions

Experts can make meaningful pairwise judgements, objective values are measured consistently, criteria are relevant to the decision, and alternatives are comparable under each criterion.

Limitations

AHP supports structured judgement but does not remove bias. Objective criteria are normalised decision inputs, not proof that the selected measures fully represent performance.

FAQ

What is the Saaty scale?

It is a 1 to 9 judgement scale used for pairwise comparison. A value of 1 means equal importance or preference, while 9 means extreme importance or preference.

Can several experts answer the same questionnaire?

Yes. Send the same questionnaire JSON to each expert, then load multiple completed response files in the analysis section. The tool aggregates judgements using a geometric mean.

Can AHP use objective data as well as expert judgement?

Yes. Mark a criterion as objective when alternatives can be compared using measured values, such as cost, on-time delivery percentage, emissions, or lead time. The tool normalises those values into local priorities while still using AHP criterion weights.

What does consistency ratio mean?

It checks whether the pairwise comparisons are reasonably coherent. A high consistency ratio means the expert should review the answers before the ranking is used.

Is my survey data uploaded?

No. This tool reads, calculates, and exports JSON files in the browser. No server upload is used by this static page.
